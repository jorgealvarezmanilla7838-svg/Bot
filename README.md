# 🧙 BotFantasy

BotFantasy es un bot de Discord desarrollado con **Node.js** que responde con información básica sobre sagas, personajes y elementos del género fantasía y cultura geek.

Este proyecto fue creado como una aplicación libre utilizando Node.js como tecnología principal.

---

## 📌 Características

- Responde comandos dentro de Discord
- Proporciona información básica sobre sagas de fantasía
- Sistema simple de reconocimiento de comandos
- Fácil de expandir agregando nuevas sagas o funciones

---

## 🛠 Tecnologías utilizadas

- Node.js
- discord.js
- dotenv
